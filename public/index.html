🛡️ Bot Constraints & Storage Rules
  • < 2 MINS
    Max Video Duration: Videos and Reels longer than 2 minutes (120 seconds) are automatically rejected.
  • 50 MB
    Max File Size Limit: Media downloads are aborted if they exceed 50 MB (Telegram Bot API limit).
  • MULTI-PLATFORM
    TikTok, Instagram & Facebook: Downloads TikTok videos & photo slideshows, Instagram Reels & posts, and Facebook Reels.
  • PUBLIC ONLY
    Private Reel Guard: If a Reel is private, restricted, or cannot be seen, the bot displays a clear message stating it cannot download non-public media.
  • EPHEMERAL
    Auto-Cleanup Storage: Videos are temporarily written to the project's ./downloads folder, dispatched to Telegram without captions, and immediately deleted.

🤖 Telegram Bot Usage

1. Open your Telegram bot configured with TELEGRAM_BOT_TOKEN.

2. Send /start to initialize the bot.

3. Paste any TikTok, Instagram Reel, or Facebook Reel URL.

4. The bot downloads the media, sends it cleanly with no return text, and deletes the local file immediately. If private or restricted, it lets you know it cannot be downloaded.
